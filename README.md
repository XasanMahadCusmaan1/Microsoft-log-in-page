# Microsoft Sign-In Page — UI Practice

An unofficial visual recreation of a Microsoft-style sign-in screen for frontend practice.

## Features and current scope

- Sign-in layout and branding elements.
- Account-help links and sign-in options.

## Built with

HTML, CSS, and vanilla JavaScript. No package installation or build step is required.

## Run locally

Clone or download this repository, then serve its root with a local static server, such as VS Code Live Server. Open the address provided by the server. Serving the repository root preserves root-relative asset paths.

## Project structure

- `index.html`
- `style.css`
- `main.js`

## Learning focus

Page structure, spacing, form-style controls, and reproducing an interface with CSS.

## Current limitations

main.js is empty. There is no authentication service or working account sign-in flow. Documentation reflects source inspection; browser behavior was not tested during this README update.
